## 🔑 Key Concepts

### Resource Mapping
Maps Terraform `azurerm_*` resources to Azure service names for API queries.
See: `resource_mapping.json`

### Cost Types
- **fixed**: Resources with predictable monthly costs (VMs, databases)
- **consumption**: Pay-per-use resources (storage, functions)
- **mixed**: Can be either (e.g., SQL serverless vs provisioned)
- **free**: No direct cost (vnets, subnets)

### Actions
- **create**: New resource (+cost)
- **delete**: Remove resource (-cost)
- **update**: Change configuration (±cost)
- **replace**: Delete + recreate (±cost)
